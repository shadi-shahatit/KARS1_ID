# KARS1 and Intellectual Disability

This repository contains the data, scripts, and analyses associated with the study investigating the **KARS1 c.989T>C (p.Leu330Pro) variant** in a consanguineous family in Jordan with Intellectual Disability and hearing impairment.

The repository includes the genetic, evolutionary, functional, and structural analyses performed as part of this study. For further details, please see https://doi.org/10.1016/j.gene.2026.150444.
